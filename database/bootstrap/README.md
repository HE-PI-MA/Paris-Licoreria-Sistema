# Base V2 oficial

Estos cuatro archivos son la base inicial oficial de una instalación nueva de PARÍS LICORERÍA.
No se ejecutan sobre una base que ya tenga tablas. Para una instalación vacía usa `npm run db:install`.
Las instalaciones existentes se actualizan con las migraciones U004, U012, U023, U030, U031 y U039; no deben reconstruirse.
